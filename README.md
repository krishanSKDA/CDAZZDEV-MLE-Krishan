## Before running anything
1. Rename this folder / repo to `CDAZZDEV-MLE-[YourName]` and push as a
   **public** GitHub repository.
2. In Google Colab, add these as **Secrets** (key icon, left sidebar) --
   never paste them directly into any cell:
   - `MISTRAL_API_KEY` (used in all three tasks).
   - `HF_TOKEN` (free, huggingface.co/settings/tokens) -- Task 2 only, to
     push the merged fine-tuned model.
   - Weights & Biases API key -- Task 2 only, optional (console logging works without it).
3. Open each notebook directly from GitHub in Colab (File > Open notebook >
   GitHub tab), or use the Colab badges in each task's README once the repo
   is pushed.
4. Run every notebook top to bottom **before submitting** -- outputs must be
   visible, not cleared (see Section 2.3 of the assessment).
